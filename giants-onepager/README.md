# Giants Network One‑Pager

A simple static one‑pager mockup to explain the Giants Network concept. Share this link in docs, social posts, or investor updates.

## Preview locally

```bash
python3 -m http.server 8080
# open http://localhost:8080/giants-onepager/index.html
```

## Deploy

- Netlify: drag `index.html` into a new site
- Vercel: `vercel` in the `giants-onepager` folder
- GitHub Pages: place files in a `/docs` folder and enable Pages on `main`
- Surge: `surge /workspace/giants-onepager giants-onepager.surge.sh`

## Customize

- Update copy in `index.html`
- Swap the inline SVG under the “Queryable expertise” section for a different visual
- Replace fonts/colors by editing the `<style>` block in `index.html`
