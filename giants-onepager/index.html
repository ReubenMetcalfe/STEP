Turn teaching and learning into a verifiable professional asset

Giants Network is a self‑sovereign, reputation‑based platform where every participant both teaches and learns. Sessions are co‑attested, outcomes are linked to real artifacts, and expertise becomes queryable across the network.

Core concept

No legacy credentials. Reputation emerges from verifiable activity: mutual session attestations, artifacts, and outcomes. Identity is self‑sovereign and claims are portable.

1. Create a profile (DID) and list availability or learning goals.
2. Book a session. Align on goals, scope, and time (1‑4h).
3. Co‑attest the session within 48h with a link to artifacts.
4. Build portable reputation and discover lineages.

Availability‑first matching

Search by skill and time window. Sort by verified hours, teaching outcomes, completion rate, and timezone proximity.

⏱️ Time‑boxed sessions prevent burnout (1‑4h)
🧩 Controlled skill taxonomy for consistent tagging
🔗 Artifacts required: links to code, notes, or outcomes
🤝 Mutual signatures: both parties must confirm

Session types

  • Teaching sessions: share expertise 1‑on‑1 or small groups
  • Learning requests: targeted help with context
  • Project pairing: work on real problems with shared outcomes
  • Code Roulette: optional auto‑matching on preferences

Composable reputation

Built from interaction history, not claims. Each session yields a signed record; ratings are bounded by rater credibility.

📚 Decayed verified hours per skill
✅ Completion rate with no‑show penalties
⭐ Teaching quality weighted by credible raters

Integrity guardrails

🧪 Reciprocity throttle: diminishing returns for repeated pairs
🧾 Artifact requirement: missing links cap hours
🕵️ Anomaly flags for collusion clusters

Simple scoring model

Per skill, rankings combine activity and outcomes:

w1 × decayed_verified_hours
+ w2 × quality_score × log(1 + unique_apprentices)
+ w3 × completion_rate
